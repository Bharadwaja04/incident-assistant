# app_core: the incident-report logic in TypeScript

Pure TypeScript (no React Native dependency), a port of the Python reference. Drop `src/` into the React Native app.

```ts
import { Extractor } from "./src/extractor";
import { Session } from "./src/session";

const ex = new Extractor({ baseUrl: "http://127.0.0.1:8080/v1", model: "qwen3-1.7b", mode: "tools" }); // llama-server on the device
const session = new Session(ex, store);                    // store.save(fields, transcript, flags) -> id
const r = await session.turn({ text: whisperText });       // r.message = next question, r.draft = fields, r.flags = badges, r.ready = go to review
await session.voiceEdit("sorry it was 10:35 pm");          // review-screen mic
await session.submit(); speak(session.summary());
```

- `src/schema.ts`: normalise, time parsing, `resolveTime` (the function the model calls), grounding, evidence spans.
- `src/extractor.ts`: model calls (tool calling, focused checks for type/place/time/severity).
- `src/session.ts`: the dialogue (questions, confirmations, corrections, hand-over to the form).
- `src/generated.ts`: generated by `python tools/gen_config.py` from `config/` and the Python prompts. Do not edit; re-run after changing a prompt.

Tests (`npm test`, Node 22): `golden` 60 cases from `eval/golden_cases.json`, `extractor` and `session` against a scripted fake model.

Not ported yet: the AI cleaning layer, audio filters, fluency notes (the speech side), and the SQLite store (use the app's storage).
